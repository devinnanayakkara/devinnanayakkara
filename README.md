## Selected Projects

### Project Management and Task Management System

A full-stack project management application with separate frontend and backend repositories.

- [Frontend](https://github.com/devinnanayakkara/Project-Management-Task-Management-System-Frontend) — React, Vite, Ant Design, Axios, React Router, and JWT decoding.
- [Backend](https://github.com/devinnanayakkara/Project-Management-Task-Management-System-Backend) — Java 21 and Spring Boot REST service with Spring Security, JWT support, and MySQL.

A React ecommerce interface paired with a Node.js API and MongoDB-backed product data.

- [Backend](https://github.com/devinnanayakkara/ecommerce-backend) — Node.js, Express, Mongoose, CORS, and environment configuration.
